# Fonts Needed for LockBudget Figma Import

All text in the exported SVGs is strictly mapped to:
- **Font Family**: `Source Sans 3` (Google Font)
  - No fallback chains
  - Available natively in Figma by default

## Weights Used Across Screens

| Weight Value | Common Name | Usage in UI |
| :--- | :--- | :--- |
| `400` | Regular | Body copy, secondary descriptions, timestamps |
| `600` | SemiBold | Row labels, card metadata, button badges |
| `700` | Bold | Screen titles, card headings, amounts, primary CTAs |
| `800` | ExtraBold | Key metrics, prominent numerical totals |

## Local Installation Status

- **Figma Web & Desktop**: `Source Sans 3` is a built-in Google Font. No manual font download or font installer is required when opening or pasting in Figma.
- **Local Workspace**: Official `Source Sans 3` OpenType fonts (`SourceSans3-*.otf`) are installed at `~/.local/share/fonts/` for Chromium and Resvg rendering verification.
